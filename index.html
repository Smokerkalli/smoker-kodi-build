So richtest du das Repo ein

  1. Quelle hinzufügen

    Öffne in Kodi Einstellungen → Dateimanager → Quelle hinzufügen. Trage diese Adresse ein und nenne die Quelle „Smoker Repo“.

    https://smokerkalli.github.io/smoker-kodi-build/

  2. Repository installieren

    Wähle Add-ons → Aus ZIP-Datei installieren → Smoker Repo und dann repository.smoker-1.0.1.zip. Aktiviere bei Bedarf „Unbekannte Quellen“.

  3. Add-on auswählen

    Öffne Aus Repository installieren → Smoker Repository. Einzelne Add-on-ZIPs findest du auch in der Dateiliste.
